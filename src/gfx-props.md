# Графика CH2-03 — свойства компонентов (для сборки на Sonnet)

Вёрстку не менять: только данные в `public/ch2-03/board.mjs` (вне репозитория, копия на Диске).
Код: схемы — `src/ch203-gfx.tsx`, оверлеи (`big`, `src`, `counter`, `label`, `clock`) — `src/long.tsx`.
После правки данных: `node scripts/ch203-build.mjs` (и `--draft` для черновика) → `props.json` / `props-draft.json`.

## Общие правила (зашиты в код)
- Сетка 1920×1080: поля 96 px слева и справа, верх 64 px (часы-дата слева, метка справа), заголовок схемы — по центру, базовая линия y 196, ничего ниже y 900.
- Зона плашки G5 — справа сверху, x 1404–1824, y 214–454: пока идёт счётчик, графика туда не заходит.
- Вход и выход любой схемы и оверлея — `IO = 9` кадров (проявление + подъём на 12 px). Подложка двигается только медленным наездом 1,06 → 1,10, без дрожания.
- Шрифты: главные подписи ≥ 56 px, остальные подписи и источники ≥ 42 px.

## Схемы: `X(глава, привязка, { kind, data })`

### Общие поля всех схем (кроме `quote`, `sheet`)
| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `bg` | имя файла кадра в папке ролика | — (уголь) | размытая тёмная подложка; в черновике `.webp/.png` → `.jpg` автоматически |
| `bgBright` | 0–1 | 0,45 | яркость подложки |
| `bgBlur` | px, 6–10 | 8 | размытие подложки |
| `tag` | строка | — | метка `ESQUEMA…` справа сверху (плашка, Oswald 600, 42 px) |

### `basin` — G1, карта бассейна
| Поле | Значения | Пример |
|---|---|---|
| `mode` | `"1960"` (тако, пульс на городе) / `"1575"` (круг на озере, годы) | `"1960"` |
| `lake` | название озера | `"ОЗЕРО"` |
| `lakes` | подпись цепи озёр, под ней | `"7 LAGOS"` |
| `river`, `tacos`, `sea` | подписи (sea — по словам в столбик) | `"RÍO SAN PEDRO"`, `"3 TACOS"`, `"OCÉANO PACÍFICO"` |
| `towns` | `{ loslagos, antilhue, valdivia, corral }` | `"LOS LAGOS"` … |
| `focus` | `"taco"` — наезд 1 → 1,25 на тако | — |
| `y1`, `y2`, `old` | только `1575`: годы над и под озером, старое название | `"ГОД 1"`, `"ГОД 2"`, `"СТАРОЕ НАЗВАНИЕ"` |
| `scale` | подпись масштабной линейки (снизу по центру) | `"≈ 20 KM"` |
Пример: `{ kind: "basin", data: { mode: "1960", lake: "ОЗЕРО", lakes: "N ОЗЁР", towns: {…}, sea: "ОКЕАН", tag: TAG, bg: "NXX.webp" } }`

### `flood` — G10, карта затопления
`title` (дата, Cinzel 72, по центру сверху), `towns` (4 строки по реке: Los Lagos, Antilhue, Pishuinco, Valdivia), `river`, `sea`, + общие поля.
Пример: `{ kind: "flood", data: { title: "ДАТА", towns: ["ГОРОД 1", "ГОРОД 2", "ГОРОД 3", "ГОРОД 4"], river: "РЕКА", sea: "ОКЕАН", tag: TAG, bg: "NXX.webp" } }`

### `subsid` — G2, земля опустилась
`title`, `delta` (Cinzel 120, лава), `before`, `after` (56 px). Подложка: N49 (когда будет) или N15.
Пример: `{ kind: "subsid", data: { title: "ЗАГОЛОВОК", delta: "≈ −N M", before: "ДО", after: "ПОСЛЕ", tag: "ESQUEMA", bg: "NXX.webp" } }`

### `sil` — G6, дом и завал
`floors` (число этажей, 3,1 м на этаж), `level` (цифра уровня), `title`. Шкала 0–30 м.
Пример: `{ kind: "sil", data: { floors: 8, level: "+N M", title: "ЗАГОЛОВОК", tag: "ESQUEMA", bg: "NXX.png" } }`

### `bar` — G3, столбик
`big` (Cinzel 250), `unit` (88), `sub` (64).
Пример: `{ kind: "bar", data: { big: "+N M", unit: "ЕДИНИЦА", sub: "ПОДПИСЬ", tag: "ESQUEMA", bg: "NXX.png" } }`

### `corr` — G4, поправка
`old` (зачёркивается), `neu` (Cinzel 180, лава), `area`, `source` (42). Центр — x 820 (справа плашка G5).
Пример: `{ kind: "corr", data: { old: "СТАРОЕ", neu: "НОВОЕ", area: "ПОДПИСЬ", source: "Fuente: …", tag: "ESQUEMA", bg: "NXX.png" } }`

### `eros` — G8, размыв
`steps` — ровно 3 слова (смена с растворением), `end` — итоговая строка.
Пример: `{ kind: "eros", data: { steps: ["ШАГ 1", "ШАГ 2", "ШАГ 3"], end: "ИТОГ", tag: "ESQUEMA", bg: "NXX.webp" } }`

### `quote` (G9) и `sheet` (G7) — без изменений
`quote`: `bg`, `blur`, `dark` (0–1), `name`, `role`, `quote`, `source`, `nameOnly`, `top` (px). `sheet`: `year`, `head`, `sub`.

## Оверлеи: `{ ch, a, dt, dur, el }`

### `big` — B7, главная цифра
| Поле | Значения | По умолчанию |
|---|---|---|
| `text` | цифра (если нет `countTo`) | — |
| `sub`, `src` | подпись под цифрой / источник (42 px) | — |
| `size`, `subSize` | кегль цифры / подписи, px | 230 / 64 |
| `align` | `"left"` (с `x`) / `"center"` | `"left"` |
| `x`, `top` | позиция, px | 96 / 230 |
| `countTo`, `countSec`, `countFrom`, `unit` | счёт 0 → `countTo` (easeOut, промежуточные размыты, цифры в слотах) | `countSec` 1,4; `countFrom` = начало оверлея |
| `punch` | удар 1 → 1,04 за 3 кадра в момент остановки счёта | — |
| `strikeDt` (в board) → `strikeAtSec`, `strikeW` | зачёркивание | — |
Хук: `{ ch: 0, a: "слово", dur: 2.7, el: { k: "big", text: "N", sub: "ПОДПИСЬ", align: "center", size: 640, subSize: 110, top: 110, countTo: N, countSec: 0.8, punch: true } }` — цифра ≈ 45–50 % высоты кадра.

### `src` — B5, источник отдельной строкой
`text`, `top` (px, справа сверху, правый край 96). 42 px.

### `counter` — G5 (в board: блок `counter`, не в `overlays`)
| Поле | Что |
|---|---|
| `keys` | `[глава, привязка, день, dt?]` — опорные точки дня, между ними линейно |
| `total`, `meters` | `total` дней ↔ `meters` м: метры = день × meters / total |
| `dayLabel`, `sub`, `subSec` | «DÍA», подпись на первые `subSec` с |
| `hide` | `[[гл, привязка, dt, гл2, привязка2, dt2], …]` → `hideRanges` в секундах; растворение 9 кадров |
Плашка фиксирована: 400 × 168 px, справа 96, сверху 230; цифры в слотах одной ширины, выравнивание вправо — ширина не меняется ни на «9 → 10», ни на «+9,9 → +10,0».
Пример: `hide: [[5, "@start", -0.3, 6, "@start", 0]]` — скрыта на время главы 5.
